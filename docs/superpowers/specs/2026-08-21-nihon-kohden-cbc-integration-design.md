## 1. Goal & Architectural Overview

Provide an offline-first, non-intrusive integration mechanism for the **Nihon Kohden MEK-7222 Hematology Analyzer** to allow laboratory technicians to capture all 22 CBC parameters directly into the M-LIS by pasting raw instrument output, while keeping manual per-parameter editing available.

In addition, render CBC results in their own dedicated, professionally styled page in ReportLab conforming to [`rptrchemcour.pdf`](file:///c:/Users/dell/Documents/amh-lab-tracker/docs/reference/rptrchemcour.pdf).

---

## 2. Global Constraints & Best Practices

1. **No Emojis**: Code, comments, UI, logs, commit messages.
2. **Terminology**: Always use **"Client"**, never "Patient".
3. **No Toasts**: Use clean modal dialogs for success/error alerts.
4. **Backend is the Authoritative Layer**: All parsing, field mapping, flag extraction, and data formatting happen strictly in backend Python services. Frontend is an interaction layer that calls `POST /api/integrations/parse-analyzer-output` and populates the form for human review.
5. **Calibrated Device Output Preservation**: Raw numbers and device flags (`*`, `H`, `L`, or `None`) are captured exactly as generated by the instrument without mutation.

## 3. Nihon Kohden Output Mapping Matrix

Input format from Nihon Kohden MEK-7222:
- **Line 1**: Header, metadata (Sample ID, Date, Time), followed by 22 parameter values and flags.
- **Line 2**: Reference range bounds from device.

The 22 parameter tokens map in exact sequence:
1. `Total WBC Count (White Blood Cells)` -> Token 1 (e.g. `4.1`)
2. `Neutrophils (%) [Relative Count]` -> Token 2 (e.g. `30.4*`)
3. `Lymphocytes (%) [Relative Count]` -> Token 3 (e.g. `55.3*`)
4. `Monocytes (%) [Relative Count]` -> Token 4 (e.g. `10.0*`)
5. `Eosinophils (%) [Relative Count]` -> Token 5 (e.g. `2.7*`)
6. `Basophils (%) [Relative Count]` -> Token 6 (e.g. `1.6*`)
7. `Neutrophils (Absolute Count)` -> Token 7 (e.g. `1.3*`)
8. `Lymphocytes (Absolute Count)` -> Token 8 (e.g. `2.3*`)
9. `Monocytes (Absolute Count)` -> Token 9 (e.g. `0.4*`)
10. `Eosinophils (Absolute Count)` -> Token 10 (e.g. `0.1*`)
11. `Basophils (Absolute Count)` -> Token 11 (e.g. `0.1*`)
12. `Red Blood Cells (RBC)` -> Token 12 (e.g. `6.92H`)
13. `Hemoglobin (Hb)` -> Token 13 (e.g. `16.9`)
14. `Hematocrit (HCT)` -> Token 14 (e.g. `52.7H`)
15. `Mean Cell Volume (MCV)` -> Token 15 (e.g. `76.2L`)
16. `Mean Cell Hb (MCH)` -> Token 16 (e.g. `24.4L`)
17. `Mean Cell Hb Conc (MCHC)` -> Token 17 (e.g. `32.1`)
18. `RBC Distribution Width (RDW)` -> Token 18 (e.g. `12.9`)
19. `Platelets Count (PLT)` -> Token 19 (e.g. `175`)
20. `Thrombocrit (PCT)` -> Token 20 (e.g. `0.13L`)
21. `Mean Platelet Volume (MPV)` -> Token 21 (e.g. `7.6`)
22. `PLT Distribution Width (PDW)` -> Token 22 (e.g. `17.6H`)

## 4. Components & Interfaces

### A. Backend Parser (`backend/app/parsers/nihon_kohden.py`)
- `parse_nihon_kohden_output(raw_text: str) -> dict`:
  - Returns `{"status": "success", "sample_id": str, "timestamp": str, "parameters": list[dict]}`.
  - Each parameter item: `{"name": str, "value": str, "flag": Optional[str], "unit": str}`.

### B. Integration API Router (`backend/app/routers/integrations.py`)
- `POST /api/integrations/parse-analyzer-output`:
  - Body: `{"analyzer_type": "nihon_kohden", "raw_text": str}`
  - Validates format, runs parser, returns structured JSON.

### C. Frontend Result Entry Workflow (`frontend/static/js/app.js`)
- If test is `Complete Blood Count (CBC)`:
  - Add button `[ Paste from Analyzer ]` in modal header.
  - Collapsible textarea with `[ Parse & Populate ]` and `[ Cancel ]`.
  - On parse, matches parameter names to input elements and populates them.
  - User can manually edit/review before clicking "Save Result".

### D. Dedicated ReportLab CBC Report Page (`backend/app/pdf_generator.py`)
- Check if visit results contain CBC.
- If CBC is present, render `HAEMATOLOGY CBC REPORT` on a dedicated clean page layout styled per [`rptrchemcour.pdf`](file:///c:/Users/dell/Documents/amh-lab-tracker/docs/reference/rptrchemcour.pdf):
  - Client details header box.
  - 4 clean categorized sub-sections: Main/Indices, Relative Differential (%), Absolute Differential, RBC/PLT Indices.
  - Columns: `Test`, `Result`, `Units`, `Flag`, `Ref. Ranges`.
  - Dynamic biological reference intervals based on client age/sex.
  - Technologist signature block at bottom.
