# M-LIS Report Letterhead & Facility Customization Guide

This directory holds the background letterhead graphics and facility metadata applied to official diagnostic result slips and performance PDF reports generated by M-LIS.

---

## Report Letterhead Background Designs (A4 Format)

M-LIS dynamically layers diagnostic test tables and vector charts over standard A4 portrait background images (210 × 297 mm, recommended resolution: 2480 × 3508 px at 300 DPI, PNG format).

Facilities can optionally prepare up to **four graphic variations** to achieve clean multi-page document presentation without repeating large header banners or footer contact bars on intermediate pages:

| Suggested File Name | Document Context | Recommended Graphic Layout |
| :--- | :--- | :--- |
| `letterhead.png` | **Single-Page Documents** | **Full Letterhead:** Includes top facility header banner, subtle center watermark, and bottom contact / accreditation footer. Used for single-page client test results and 1-page reports. |
| `letterhead-header+watermark_only.png` | **First Page of Multi-Page Reports (Page 1 of N)** | **Header + Watermark:** Top header banner and center watermark, without the bottom footer banner. Leaves maximum vertical space for data tables. |
| `letterhead-watermark_only.png` | **Middle Pages (Pages 2 to N-1)** | **Watermark Only:** Center watermark only, with clear top and bottom margins for uninterrupted continuous tabular data. |
| `letterhead-footer+watermark_only.png` | **Final Page of Multi-Page Reports (Page N of N)** | **Footer + Watermark:** Center watermark and bottom contact / sign-off footer banner, cleanly closing the document. |

### Fallback Behavior
Providing all four variations is **optional**. If a facility only supplies the standard single-page `letterhead.png`, M-LIS will automatically use it across all pages without layout errors.

## Facility Information & Metadata Configuration

Facility contact information, acronyms, and report headers can be configured via:

1. **Admin Panel UI (Runtime):** Navigate to **Admin Panel -> Facility Settings** to customize the facility name, acronym, address, phone number, and email.
2. **Default JSON Preset (`theme.json`):** Set default institution details in `assets/branding/theme.json` for automated or offline installations:

```json
{
  "facility_name": "Your Facility Name",
  "facility_acronym": "YFN",
  "facility_code": "LAB",
  "address": "P.O. Box XXXX, City, Country",
  "phone": "+256 700 000 000",
  "email": "lab@facility.org"
}
```
